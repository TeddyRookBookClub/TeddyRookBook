\chapter{Reproducibility}\label{app:repro}

The full source of this work, including the \LaTeX{} files, the bibliography and every script, is kept with the companion site's source under \texttt{docs/papers/rhythm-of-numbers/}. Running the scripts in order regenerates every figure (\texttt{paper/figures/}) and every number in the text: each script writes a file of \LaTeX{} macros to \texttt{paper/gen/}, and the text uses only those macros for computed values. Scripts stop with an error if any asserted fact fails.

\paragraph{Building.} With Python 3 and the packages of Appendix~\ref{app:methods} installed, run \texttt{sh run\_all.sh} in \texttt{compute/}, then \texttt{latexmk -xelatex main.tex} in \texttt{paper/}. Random choices use fixed seeds, so a rebuild reproduces the same numbers, except that the GUE samples (seeded too) and timings may differ across library versions in the last digit.

\paragraph{Provenance of non-computed facts.} Dates, names and bibliographic details were checked against the sources listed in the bibliography. The musical facts about the Suite come from the companion site's data file \texttt{data/music/suite.yaml}, compiled from the engraved score.
