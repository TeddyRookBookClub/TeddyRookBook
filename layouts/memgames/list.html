The technique in each game

  • Memory Palace Builder: the memory palace (method of loci). A place you know holds things in order.
  • Chunk It: chunking. A few meaningful groups beat many loose digits.
  • Story Chain: the link method, a kind of mnemonic. Each picture leads to the next.
  • Card Pairs: picture plus words, with spaced review. Two paths to the same memory, and misses come back sooner.
  • Daily Memory Warm-up: retrieval and spacing. Your own lists, on schedule.
