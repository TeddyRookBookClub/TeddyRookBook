How these pages are written

  • Evenhanded. Both sides get the same number of arguments, each in its strongest form, and each followed by the best answer from the other side. Teddy Rook Book doesn’t pick a winner.
  • Sourced. Background facts link to their sources. Where the facts themselves are disputed, the page says so and gives the main positions.
  • Levels. {{ range $i, $l := $meta.levels }}{{ if $i }} {{ end }}{{ $l.label }}: {{ $l.note }}{{ end }}
  • Kinds. A policy resolution asks whether to do something; a value resolution asks whether something is good, right or more important; a fact resolution asks whether something is true. See Reading a Resolution.
