Which format should I try first?

  • Public Forum if you like current events and want a partner: speeches are short and written for any listener.
  • Lincoln-Douglas if you like big questions of right and wrong and want to debate on your own.
  • Policy if you love research and want one topic all year.
  • Congress if you like making speeches and want to try many topics in one day.
  • Oxford-style for a classroom, co-op or family night: no league needed.

Run any of them with the debate timer, which knows every speech in order.
