How the sheets work

  • Made fresh. The page builds every puzzle when you ask for it, so there's no end to them. The ones that need a single answer (sudoku, cage squares, logic grids, picture logic, letter arithmetic, piece fitting, matchsticks) are checked to have exactly one.
  • Print it again. Each sheet has a code in the corner. Type that code into Sheet code and you get the very same puzzles, so a sibling can have a clean copy, or you can share the link.
  • Answers on their own page. Print the key with the sheet, or turn it off and print it later from the same code.
  • Paper. Choose US Letter or A4. If your printer adds its own margins, pick “actual size” or “100%” in the print box.
  • Levels. Easy is a good start for most children around 7 to 9 and for anyone new to a puzzle. Medium and hard take longer and need more steps of reasoning. Mix them freely.
  • Nothing to sign up for. Your choices stay in this browser only.
