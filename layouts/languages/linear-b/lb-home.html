𐀷𐀙𐀏 Linear B and Linear A

Linear B is the oldest written Greek, pressed into clay in the palaces of Crete and the Greek mainland more than three thousand years ago and read again in 1952. Linear A, the script it came from, uses many of the same signs, yet no one can read it. Learn the story, the signs and the tablets of both.

Where to start

  • New to all of this? Read the story first (about twenty minutes, with things to try along the way).
  • Want to read a tablet? Learn the five vowels and a few rows of the grid on flashcards, then try the tripod tablet with the sign grid open beside it.
  • Studying it properly: the course Linear A and Linear B teaches it all in order, from the palaces of Crete to judging a decipherment claim.
  • Know Greek already? You’ll recognize many words once you learn the spelling rules: ti-ri-po is τρίπους, di-pa is δέπας, ku-ru-so is χρυσός.
  • Curious about other scripts? Egyptian hieroglyphs were deciphered about a hundred and thirty years earlier, with the help of the Rosetta Stone. Linear B had no Rosetta Stone.

Two scripts, one family

Linear B was adapted from Linear A, so many signs look alike. The difference is that we know Linear B’s language.
