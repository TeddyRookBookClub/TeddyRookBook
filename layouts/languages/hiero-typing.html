Type transliteration

Egyptologists type with an ordinary keyboard using the Manuel de Codage (MdC), a standard worked out in the 1980s: A for ꜣ, H for ḥ, x for ḫ and so on. Type in either box; the other one follows. Then copy.

Reading it

The typing table

Capital letters matter only for A H x X S T D (and a versus A): h is plain h and H is ḥ. Everything else passes through as typed, including the separators Egyptologists use: . before an ending (sḏm.n), = before a suffix pronoun (pr=f) and - inside compounds.
