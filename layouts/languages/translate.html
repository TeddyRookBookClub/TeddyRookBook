❓ How the reader works
  1. Pick a plan, then work through it a day at a time with ‹ ›, or pick a day from the list. Go to jumps to the day where a {{ if eq .Params.work "john" }}chapter{{ else }}book{{ end }} starts.
  2. Read the {{ if $grc }}Greek{{ else }}Latin{{ end }} aloud once, then translate it. {{ if eq .Params.work "aeneid" "iliad" }}The numbers are line numbers in each book, so 1.33 is Book 1, line 33; every fifth is in bold.{{ else if eq .Params.work "john" }}The small numbers are verses.{{ else if eq .Params.work "catiline" }}The small numbers are the speech’s sections (§1 to §33).{{ else }}The small numbers are chapter and section, so 3.4 is chapter 3, section 4.{{ end }}
  3. Tap any word for links to the dictionaries: the Perseus Word Study Tool (which lists the possible forms and opens {{ if $grc }}Liddell and Scott{{ else }}Lewis and Short{{ end }}) and Logeion.
  4. Write your translation in the box. It saves in this browser as you type (one box for each day). Print the day, or save all your translations as a text file.
  5. Check your translation shows a public-domain English translation of the same lines. It is one translator’s choice of words, not the only right answer.
  6. Done marks the day; the count at the top shows how many you have finished. A Life Planner session opens the reader at exactly its lines.

This browser isn’t letting the page save, so your translations and ticks won’t be kept. Copy your work somewhere safe before you leave.
