⭐ How a day adds up to about {{ $M.goal }} XP

The ladder gives {{ $M.xp }} XP for every right answer on a Great Books rung, in learning, extra practice and review, and a {{ $M.bonus }} XP bonus the first time you pass a rung (three right, the last two in a row). The daily goal starts at {{ $M.goal }} XP.

{{- $da := index (where $P "k" "a") 0 }}{{ $db := index (where $P "k" "b") 0 }}{{ $dr := index (where $P "k" "review") 0 }} {{- $right := math.Round (mul (index $da.q 1) $M.acc) }}
  • Day 1 of a rung: {{ index $da.q 1 }} questions. If about 4 in 5 are right, that is {{ $right }} × {{ $M.xp }} = {{ mul $right $M.xp }} XP, plus the {{ $M.bonus }} XP pass bonus: about {{ index $da.x 1 }} XP.
  • Day 2: {{ index $db.q 1 }} more questions on the rung and a review round of {{ index $db.r 1 }} from the Practice page: about {{ index $db.x 1 }} XP.
  • Review and catch-up days: {{ index $dr.q 1 }} questions, about {{ index $dr.x 1 }} XP.
  • Young readers answer a few fewer ({{ index $da.q 0 }} on day 1, {{ index $dr.q 0 }} on most other days): about {{ index $db.x 0 }} to {{ index $da.x 0 }} XP.

After you pass a rung, press Keep practicing to go on; those answers still earn XP. Your XP is saved with the rest of the ladders and shows on your progress page.

🏡 Three ways to take the year

  • Young reader. Children of about 8 to 12 read the young readers’ path, try its activity, and answer a little less practice. A parent can read along.
  • Teen or adult. The full lesson on day 1, Going deeper and the family questions on day 2.
  • Family read-aloud. Read the young readers’ path aloud together, then take turns answering. Older readers can add the full lesson. Use one learner on this device for the family so the XP adds up in one place, or give each child their own learner.

The order is the same on every track: era by era, roughly in the order the books were written, with stories, philosophy, history and science taking turns. {{ $C.two }} rungs get two days and {{ $C.one }} shorter ones get one, with {{ $C.review }} review days and {{ $C.catch }} catch-up days along the way.
