Embeds: one line of HTML

Each embed is a small page on teddyrookbook.com made to sit in a frame on another site. It has no menus or ads, it works from 280 to 900 pixels wide, and it always shows a small “From Teddy Rook Book” link. Because it runs on this site, it gets every fix and new lesson on its own. Paste the code where you want it to appear.

Progress in a practice embed is kept in the visitor’s browser, inside the frame. Browsers keep a framed page’s storage apart from the same site opened in its own tab, so a learner’s embed progress and their progress on teddyrookbook.com don’t mix. Each embed says so in small print, with a link to open the same thing on the full site. If a browser blocks storage in frames, practice still works; it just isn’t saved.

The toolkit: run it yourself

For developers who want the practice on their own server or in their own app, with no connection to this site. One zip file holds:

  • The engine: the answer checker, the math typesetter, the answer box, the mastery and review engine and the problem card (plain JavaScript and CSS, no outside libraries).
  • Twelve ladders: Math, Physics, Chemistry, Biology, Earth & Space, Writing & Grammar, Vocabulary, Logic, Geography, American History & Civics, Economics and Etiquette, each with its topic maps, lessons, problem generators and visuals.
  • Vocabulary: the 1,000-word list with meanings, memory hooks and the drawings for each word.
  • The Family Study units (one theme for the whole family, each child at their level).
  • An example page that runs practice for any topic, with no internet connection, and a second one (language.html) that reads a Gospel passage in Greek with the King James Version, a word at a time.
  • Language packs: the Greek and Latin Gospels word by word, the classical sentences, the King James Version for the verses used, the Greek alphabet lessons and the cartouche maker. Each pack has its own LICENSE and CREDITS file; see the table below.
  • The licenses, a list of the outside pieces and their licenses, and a short README.
