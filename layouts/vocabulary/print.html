Print word cards

Choose any set of word cards, lay them out, then print them or save them as a PDF. Each card has its picture, memory hook, meaning, example and roots, and every card is fitted to its space before you print. Black-and-white printing works too: every picture has clear outlines.

3. Print or save as PDF

To save a PDF: in the print window, choose Save as PDF (or Microsoft Print to PDF) as the printer or destination. Keep the margins at Default and the scale at 100%, and turn on Background graphics so the pictures and highlights print. On a phone, use Share, then Print; the preview there can be saved as a PDF too.
